Код для створення фавікону вкладці,також виділення картинки,та змінення його розмірів
1. Адреса самого сайту з текстом:http://127.0.0.3:3000/
2. Для відкриття картинки додайте /image
3. Для змінення розміру вкажіть /image/x/y (x,y - будь яке число)
